# PNAS Submission Checklist

## Formatting & Compliance
- [ ] Word count check (PNAS limit: ~4,000 words for Research Articles)
- [ ] Reference count check (PNAS limit: ~50 references)
- [ ] Abstract ≤ 250 words
- [ ] Significance statement 50–120 words
- [ ] Confirm 6 main-text figures (PNAS allows up to 6)
- [ ] Data availability statement (required by PNAS)
- [ ] Code availability statement
- [ ] ORCID for corresponding author
- [x] Cover letter (drafted; includes editor suggestions and six suggested reviewers)

## Content Quality
- [ ] Full proofread of main text
- [ ] Full proofread of SI appendix
- [ ] Verify all SI cross-references match (we just did this, but re-verify after any edits)
- [ ] Check all equations render correctly in PDF
- [ ] Verify figure quality/readability at print size
- [ ] Confirm all citations resolve (no `?` in PDF)

## Synthetic Review Round
- [ ] Generate tough reviewer critiques and address them proactively
- [ ] Identify weakest claims and either soften language or add evidence
